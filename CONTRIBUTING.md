# Hissa qo‘shish

Taklif, xato yoki yaxshilash g‘oyasi bo‘lsa, issue oching. Kod o‘zgarishlari uchun kichik va aniq pull request yuboring.

## Ish jarayoni

1. Yangi branch yarating.
2. O‘zgarishni bitta vazifaga yo‘naltiring.
3. Maxfiy ma’lumot, haqiqiy xodim ma’lumoti yoki `.env` faylini commit qilmang.
4. PR tavsifida nima o‘zgargani va qanday ishga tushirilgani haqida yozing.

## Mahalliy ishga tushirish

`.env.example` dan `.env` yarating, qiymatlarni sozlang va `docker compose up --build` buyrug‘ini ishlating. O‘zgarishlarni yuborishdan oldin tegishli API va bot oqimlarini o‘zingizning muhitda tekshiring.
